## Telegram-бот с играми на звезды (Vercel-ready)

Этот проект — минимальный Telegram-бот, подготовленный для деплоя на Vercel.  
Сейчас он отвечает на команду `/start` приветственным текстом о приложении с играми на звезды, разными режимами, онлайн-играми и играми с ботами.

### Структура

- **`package.json`**: базовая конфигурация Node-проекта.
- **`vercel.json`**: указание, что функция `api/telegram.js` должна работать на Node.js 18.
- **`api/telegram.js`**: серверлес-функция, которая выступает как вебхук Telegram.

### Как развернуть на Vercel

1. **Установи Vercel CLI (по желанию)**:
   - `npm i -g vercel`

2. **Залогинься**:
   - `vercel login`

3. **Задеплой проект** (запусти из корня проекта — папки с этим README):
   - `vercel`
   - Следуй инструкциям в терминале (создать новый проект, выбрать аккаунт и т.п.).

4. **Найди URL проекта**  
   После деплоя у тебя будет адрес вида:
   - `https://имя-проекта.vercel.app`

   Вебхук бота будет на маршруте:
   - `https://имя-проекта.vercel.app/api/telegram`

### Переменные окружения на Vercel

1. Зайди в панель Vercel → твой проект → **Settings** → **Environment Variables**.
2. Добавь переменную:
   - **Name**: `TELEGRAM_BOT_TOKEN`
   - **Value**: токен твоего бота от `@BotFather`
3. Сохрани и сделай новый деплой (или `vercel --prod` локально).

### Настройка вебхука Telegram

После того как проект задеплоен и добавлен токен:

1. Подставь свои значения:
   - `BOT_TOKEN` — твой токен от `@BotFather`
   - `YOUR_VERCEL_URL` — адрес проекта без слеша в конце (например, `https://имя-проекта.vercel.app`)

2. Открой в браузере:

   `https://api.telegram.org/botBOT_TOKEN/setWebhook?url=YOUR_VERCEL_URL/api/telegram`

   Пример:

   `https://api.telegram.org/bot123456789:ABCDEF1234567890/setWebhook?url=https://stars-games-bot.vercel.app/api/telegram`

3. В ответ должно прийти JSON с `ok: true`.

Теперь, когда пользователь нажмет кнопку «Start» у бота (команда `/start`), серверлес-функция на Vercel получит апдейт и отправит приветственный текст.

### Что дальше

- Можно добавить команды и меню.
- Можно подключить разные режимы игр, онлайн-игры и игры с ботами, используя ту же архитектуру: все апдейты приходят в `api/telegram.js`, там ты маршрутизируешь команды и действия.
